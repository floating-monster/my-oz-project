# 📖 My Oz Project (오즈 패밀리 프로젝트)

This project is a public domain-based web service utilizing the original characters and illustrations from *The Wonderful Wizard of Oz* (1900).

---

## 📚 Source & Public Domain Information / 원작 및 출처 정보

### 🇰🇷 한국어
* **제목:** 오즈의 마법사 (*The Wonderful Wizard of Oz*)[cite: 3]
* **저자:** L. 프랭크 바움 (L. Frank Baum)[cite: 3]
* **삽화가:** W. W. 덴슬로우 (W. W. Denslow)[cite: 3]
* **출판 도시 및 연도:** 시카고, 1900년 4월 (Chicago, April, 1900)[cite: 3]
* **원작 아카이브 출처:** [Project Gutenberg EBook #43936](https://www.gutenberg.org/ebooks/43936)[cite: 3]

* **라이선스 안내:** 본 프로젝트에 사용된 텍스트, 캐릭터 설정(Dorothy, Toto, Tin Woodman, Scarecrow, Lion) 및 초기 삽화는 1900년 출판된 초판본을 바탕으로 합니다[cite: 2, 3]. 만료된 퍼블릭 도메인 자산이므로 저작권 및 상표권의 제약 없이 자유롭게 활용할 수 있습니다[cite: 2, 3].
